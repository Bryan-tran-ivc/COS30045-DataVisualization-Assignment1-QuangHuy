# Import guide — simplified October workflow

This `.knwf` is a copy of the student's simplified 26-node workflow, with the original `tv_2026_10_03.csv` placed in its workflow data area. The student's Desktop archive has not been altered. The workflow is for the Televisions page's Exercise 3 story, using only the 3 October snapshot.

## Import and inspect

1. Import `Wattwise_Star_Rating_Trap.knwf` into KNIME Analytics Platform under a new workflow name.
2. CSV Reader is configured for **Current workflow data area** and should read `data/tv_2026_10_03.csv`. If KNIME asks for a path, select that imported file.
3. Follow the left-to-right cleaning and transformation spine, then the three Bar Chart branches. Open the saved views of **Bar Chart 21** (55″/3-star versus 75″/5-star), **Bar Chart 30** (12 size × rating groups) and **Bar Chart 25** (65″/3-star versus 65″/7-star). The webpage also displays the student's screenshots of these views.
4. The native screenshots do not show group labels, so consult the explanatory text and exact-value tables on `televisions.html` before presenting them.

The three Bar Chart nodes have saved `EXECUTED` states in the supplied archive. There is no all-pairs branch or CSV Writer in this 26-node version. The 715 possible comparisons follow logically from the two non-overlapping observed ranges: 55″/3-star maximum 532 is below 75″/5-star minimum 550 kWh/year.

The listing-row sensitivity medians (513 and 598.5 kWh/year, versus registration medians 514 and 598) come from the independent CSV analysis script, not this simplified KNIME workflow. They are descriptive checks, not a correction for market representativeness.

The site's `data/star-trap-*.csv` files and custom graphics were generated by `scripts/analyse_star_trap.py` as an independent check, not exported by KNIME. The repackaged `.knwf` has **not** been rerun after import; inspect it in your KNIME installation before submitting. Compatibility with older releases is unverified.
